Multilingual support is not just a prompt change. It impacts gateway routing, input guardrails, policy RAG retrieval, flight tool payloads, regex/filter logic, and final response language.

We need an input/output language interpretation layer so user queries are normalized before agents/tools, and responses are returned in the right language/style. This needs proper design and regression testing across Flight, Trip Planner, Policy, and Guardrails, so it will take some time.
