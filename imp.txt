```markdown
Fix `suggestedQuestions` generation in the Extractor Agent.

Context:
After every agent interaction, we call the Extractor Agent with:
- current user message
- current agent response
- older summary context

Extractor Agent then updates the summary object and returns:
- updated summary context
- `suggestedQuestions: string[]`

`suggestedQuestions` are shown in UI under “You might ask”.

Important:
These are NOT questions from the agent to the user.
These should be questions/actions that the user might ask the agent next.

Current problems:
1. Some suggestions sound like the agent is asking the user.
   Wrong:
   - "When are you going to travel?"
   - "Would you like me to show cheaper flights?"
   - "Do you want to add passengers?"

   Correct:
   - "Show me cheaper flights"
   - "Add 2 adults to this search"
   - "Find flights for next weekend"

2. Suggestions repeat across multiple turns and are not refreshed based on the latest interaction.

Required behavior:
- Generate suggestions from the user’s perspective only.
- Suggestions should be based mainly on:
  - current user message
  - current agent response
  - updated summary context
- Older summary should be used only for continuity, not for stale repetition.
- Avoid repeating previous suggestions unless they are still highly relevant.
- Suggestions should help move the current journey forward.

New generation rule:
Create around 3–5 suggestions:
- 2–3 suggestions should help complete missing/unfilled summary context fields.
- 1–2 suggestions should add value to the user journey based on the current conversation.

Example:
If destination is available but origin is missing, suggest user-side actions like:
- "Add my departure city"
- "Search flights from Delhi"
- "Help me complete this flight search"

If flight results are shown:
- "Show me the cheapest flight"
- "Compare the current options"
- "Show only non-stop flights"

If filters are applied:
- "Remove this filter"
- "Show flights with checked baggage"
- "Which option is best now?"

Rules:
- Never generate assistant-side questions like:
  - "Would you like..."
  - "Do you want..."
  - "Should I..."
  - "Can I help you..."
  - "When are you..."
- Prefer user-side wording:
  - "Show me..."
  - "Find..."
  - "Compare..."
  - "Apply..."
  - "Remove..."
  - "Add..."
  - "What is..."
  - "Which option..."

De-duplication:
- Normalize suggestions before comparing:
  - lowercase
  - trim spaces
  - remove punctuation where needed
- Avoid same meaning repeated with different wording.
- Do not keep returning the same first-turn suggestions in later turns.

Output requirement:
- `suggestedQuestions` must always be an array of strings.
- Keep each suggestion short, natural, and clickable.
- Do not include explanation inside `suggestedQuestions`.

Please update:
- Extractor Agent prompt/logic
- Summary update flow if stale suggestions are being carried forward
- Tests for suggestion quality and repetition

Test cases:
1. Suggestions are always from user perspective.
2. No suggestion sounds like agent asking the user.
3. Suggestions update after each turn.
4. Repeated suggestions are avoided.
5. Missing summary fields influence 2–3 suggestions.
6. 1–2 suggestions add journey value.
7. Suggestions stay relevant to current user + agent messages.
8. Output remains `suggestedQuestions: string[]`.

Deliverable:
- Fix the issue.
- Add before/after examples.
- Add tests.
- Provide a short report explaining:
  - root cause
  - changes made
  - test results
```
