# Enhance Flight Context Validation Script

Update the existing test script to generate and run **50 single-turn flight journeys** covering `oneway`, `roundtrip`, and `multicity` (minimum 5 journeys per trip type).

Each journey should provide:

* `tripType`
* ONDs/segments
* travel dates appropriate to the trip type

Goal: verify that when the response/context contains **alternate travel dates** or **nearby airport information**, the final `flightContext` also contains the same information correctly.

For every journey capture: input, response context, final flight context, alternate-date check, nearby-airport check, pass/fail, and issue details.

Enhance the existing script only; do not create a separate testing framework.
