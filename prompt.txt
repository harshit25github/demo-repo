# Plan Flight Agent Context Intelligence Improvements

Review the current Flight Agent prompt, dynamic context hydration, conversation history usage, tool instructions, and model configuration. Do **not implement yet** — first identify why the agent keeps asking for information that is already available.

Use this priority strictly:

1. **Current user message — highest priority**
2. **Current dynamic context / search context**
3. **Relevant conversation history**
4. **Safe inference/defaults only when needed**

Expected behavior:

* If the user explicitly provides or changes a value now, that always wins.
* If the user does not provide a field, use the latest reliable value from dynamic context.
* If dynamic context also does not contain it, recover it from relevant history.
* Never ask again for information that is already reliably available.
* Combine information across turns instead of treating each message independently.
* Use tool validation/error feedback to correct recoverable inputs and retry when appropriate.

Inspect whether prompt conflicts, context hydration, history restoration, tool rules, or model configuration are preventing this behavior.

Deliver a concise plan with root causes, prompt/config changes, affected files, and test scenarios. Keep it general and intelligence-driven; do not add dozens of hardcoded cases.
