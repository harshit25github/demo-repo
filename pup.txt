Additional Requirement: System Prompt Audit & Refinement

Context:
The current system prompt is around 600 lines.
This may be causing instruction dilution, inconsistent behavior, hallucination, or less refined responses.

Required Work:
1. Audit the existing system prompt.
2. Identify:
   - repeated instructions
   - conflicting rules
   - outdated rules
   - overly verbose sections
   - unnecessary examples
   - unclear or weak instructions
   - instructions that should move to config/tests/docs instead of system prompt

Prompt Optimization Goal:
Refactor the system prompt into a shorter, cleaner, and more precise version without losing the main business logic.

Important:
- Do not remove the core behavior of the agent.
- Do not remove important guardrails.
- Do not remove mobile-specific rules.
- Do not remove routing/tool usage rules.
- Reduce duplication and rewrite instructions in plain, direct language.
- Prefer crisp rules over long explanations.

Target:
- Try to reduce the prompt from ~600 lines to around 150-250 well-structured lines if possible.
- Keep the prompt modular with sections like:
  - Role
  - Scope
  - Workflow
  - Tool Rules
  - Mobile Response Rules
  - Guardrails
  - Fallback Behavior
  - Response Style
  - Do Not Rules

Evaluation Requirement:
After refactoring, run the same end-to-end test pipeline again and compare:

Before vs After:
- average response score
- hallucination rate
- false incapability rate
- web URL leakage
- routing accuracy
- stream.error frequency
- response clarity
- internal detail leakage

Expected Output:
Provide:
1. Original prompt issues summary
2. Refactored shorter system prompt
3. List of removed/merged instructions
4. List of preserved critical rules
5. Before vs after evaluation report
6. Final recommendation on whether to use the refined prompt
