one limitation I’m seeing with the Apply Filter API is that it currently allows only one filter to be applied at a time.

In the agentic flow, a user can ask for multiple filter changes in one query, like airline, stops, price, and departure time together. Right now, we have to apply these filters sequentially through multiple API calls, which is increasing latency.

Can we consider supporting multiple filters in a single Apply Filter API request? That would help reduce repeated calls and improve the agent response time.
