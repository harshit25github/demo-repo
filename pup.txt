We have completed key enhancements in the agentic flight search workflow. The flight search agent is now synced with the app’s flight search flow, allowing user search context to move both ways — from the app listing page to the AI agent and from the AI agent back to the app. This enables continuity, so users can continue their flight search without losing context during the flow.

Current enhancements completed:

* Integrated flight search context between the app workflow and the agentic workflow.
* Enabled advanced filters in the flight agent, aligned with the filters supported by the app.
* Implemented multi-apply filter support, allowing users to apply multiple filters in a single request.
* Enhanced trip planning with flight search, multi-search, and context-aware search flows.
* Built a RAG-based policy agent using CheapoAir knowledge, covering policy-related information like airline rules, cancellation, baggage, and other support content.
* Added guardrails to keep the conversation focused on relevant travel/booking use cases.
* Enabled human handoff support when the user explicitly asks to connect with a real person.

Future work:

* Extend the agentic workflow to support hotels, cars, packages, and deals.
* Enable users to search and continue these flows through the same app-to-agent and agent-to-app continuity model.
* Expand the knowledge and action capabilities so the assistant can support more end-to-end travel planning and booking-related queries.
