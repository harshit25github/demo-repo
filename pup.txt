Important execution rule:
`update_flight_suggested_questions` is called at the end of the Flight Agent turn, after `flight_search_tool` / `apply_filter_tool` / other tools have already updated `context.flight.searchKey`.

So this tool must read the latest `context.flight.searchKey` at execution time.

Behavior:
- If latest `context.flight.searchKey` exists:
  - store the LLM-generated suggested questions in `context.flight.suggestedQuestions`.
- If latest `context.flight.searchKey` does not exist:
  - set `context.flight.suggestedQuestions = []`.
  - do not keep old/stale questions.
  - do not generate fallback questions.
