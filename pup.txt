## 1. The contract (reference behavior)

Retries happen at exactly one level: **one pending model request**. Never restart the agent run, never re-run tools that already completed, and never automatically retry the whole user turn.

**Attempts and deadlines**
- Each model request gets up to **3 attempts** with progressive total deadlines of **25 s, 50 s, 75 s**.
- A request that includes a hosted web-search tool gets **60 s, 75 s** (2 attempts), because web search alone often takes 30–45 s.
- Each new model request (each step of the agent loop) starts again at attempt 1 with the first deadline.
- The config is copied at the start of a request, so mutating it mid-flight cannot add attempts. Validation allows only 1–3 budgets and backoff of at most 2 s.

**Backoff**
- The delay between attempts is 500 ms × 2^(attempt−1), capped at 2 s (so 500 ms, then 1 s). The reference uses no jitter.
- If the provider sends `retry-after-ms`, `retry-after`, or advice `retryAfterMs`, use the largest valid value. If that value exceeds 2 s, **stop immediately** instead of waiting, because a user is waiting on a live request.
- The backoff wait is abortable.

**Hard deadline**
- Race the call against a timer and abort the provider call when the timer fires.
- **Never accept a late response from an abandoned attempt**, even if the provider ignores the abort signal.

**Streaming**
- Each attempt gets one total deadline that covers opening the stream and every read. Chunks do not extend it.
- Retry only when the attempt failed **before the first event was yielded downstream**. Once any event has been yielded, rethrow the failure and never replay it.
- `response_done` (the terminal event) means completion. Clear the timer and return without waiting for trailing reads or iterator cleanup.
- Close the iterator with `return()` as best effort, without awaiting it.

**Cancellation**
- The client `AbortSignal` wins every race. It rejects immediately, interrupts backoff, and stops any further attempt from being sent.

**Retry only transient errors**
- Timeouts (`ModelTimeoutError`).
- HTTP 408, 409, 429, 500, 502, 503, 504.
- Network errors: `ECONNRESET`, `ECONNREFUSED`, `ECONNABORTED`, `ETIMEDOUT`, `ENOTFOUND`, `EAI_AGAIN`, `EPIPE`, `EHOSTUNREACH`, `ENETUNREACH`, `UND_ERR_CONNECT_TIMEOUT`, `UND_ERR_HEADERS_TIMEOUT`, `UND_ERR_SOCKET`, `APIConnectionError`, `APIConnectionTimeoutError`, and `TypeError: fetch failed`.
- An `x-should-retry: true` header, or provider retry advice with `suggested: true`.

**Never retry these; rethrow the original error unchanged**
- Any status outside the transient set (400, 401, 403, 404, 422, and so on).
- Quota, billing, and credential codes, **even when the status is 429**: `insufficient_quota`, `billing_hard_limit_reached`, `billing_not_active`, `invalid_api_key`, `account_deactivated`, `permission_denied`.
- Aborts, refusals, behavior errors, guardrail tripwires, and `UserError`.
- Programming errors: Zod, Syntax, Range, Reference, and `TypeError` other than `fetch failed`.
- An `x-should-retry: false` header, or provider advice with `suggested: false`.

**Never replay an unsafe request, even when the error is transient**
- Server-managed state: `conversationId`, `previousResponseId`, and `conversation`, `previous_response_id`, `background`, `tools`, or `prompt` inside `providerData`, `extra_body`, or `extraBody`.
- A stored prompt without explicitly provided tools.
- Any hosted tool other than read-only web search (MCP, code interpreter, remote writes).
- An error marked `unsafeToReplay: true`, or provider advice `replaySafety: 'unsafe'`.
- A streamed attempt where the provider advice says `responseStarted: true`.

**Failure type**
- Recovery stops with `ModelDeadlineExhaustedError { attempts, reason, cause }`, where `reason` is one of `'attempts_exhausted' | 'unsafe_replay' | 'retry_after_exceeds_budget' | 'retry_advice_failed'`.
- The provider's own retry-advice call is bounded to 2 s. If it fails, the reason is `retry_advice_failed`.

**Logging**
- Log one warn line per retry: `model`, `attempt`, `timeoutMs`, `nextTimeoutMs`, `backoffMs`, `errorName`.

**Why this cannot duplicate tool executions:** the retry wraps only the model call. Tools that already ran are part of the agent's state, so the retried request sends identical input. A tool-call proposal that arrives late from an abandoned attempt loses the race and is discarded. A streamed attempt that already yielded events is never replayed.

```ts
export interface ModelDeadlineConfig {

export const modelDeadlineConfig = {

function isWebSearch(tool: ModelRequest['tools'][number]): boolean {
  return tool.type === 'hosted_tool' && ['web_search', 'web_search_preview'].includes(String(tool.providerData?.type));
}

export class ModelDeadlineExhaustedError extends Error {
  constructor(
    readonly attempts: number,
    readonly reason: 'attempts_exhausted' | 'unsafe_replay' | 'retry_after_exceeds_budget' | 'retry_advice_failed',
    cause: unknown,
  ) {
    super(`Model request recovery stopped after ${attempts} attempt(s): ${reason}.`, { cause });
    this.name = 'ModelDeadlineExhaustedError';
  }
}

/** A hard local deadline, even when the provider ignores its abort signal. */
async function withinDeadline<T>(
  work: (signal: AbortSignal) => Promise<T> | T,
  timeoutMs: number,
  parent?: AbortSignal,
): Promise<T> {
  parent?.throwIfAborted();
  const controller = new AbortController();
  let timer: ReturnType<typeof setTimeout> | undefined;
  let onAbort: (() => void) | undefined;
  const interrupted = new Promise<never>((_resolve, reject) => {
    onAbort = () => {
      // Reject first: synchronous provider abort handlers cannot win this race.
      reject(parent!.reason);
      controller.abort(parent!.reason);
    };
    parent?.addEventListener('abort', onAbort, { once: true });
    timer = setTimeout(() => {
      const error = new ModelTimeoutError({ timeoutMs });
      reject(error);
      controller.abort(error);
    }, timeoutMs);
  });
  try {
    const operation = Promise.resolve().then(() => {
      controller.signal.throwIfAborted();
      return work(controller.signal);
    });
    // Promise.race observes late rejections, but never admits late responses to Runner.
    const result = await Promise.race([operation, interrupted]);
    parent?.throwIfAborted();
    return result;
  } finally {
    clearTimeout(timer);
    if (onAbort) parent?.removeEventListener('abort', onAbort);
  }
}

const TRANSIENT_STATUSES = new Set([408, 409, 429, 500, 502, 503, 504]);
const NETWORK_CODES = new Set([
  'ECONNABORTED', 'ECONNREFUSED', 'ECONNRESET', 'EHOSTUNREACH', 'ENETUNREACH',
  'ENOTFOUND', 'EAI_AGAIN', 'EPIPE', 'ETIMEDOUT', 'UND_ERR_CONNECT_TIMEOUT',
  'UND_ERR_HEADERS_TIMEOUT', 'UND_ERR_SOCKET',
]);
const PERMANENT_CODES = new Set([
  'insufficient_quota', 'billing_hard_limit_reached', 'billing_not_active',
  'invalid_api_key', 'account_deactivated', 'permission_denied',
]);

function header(chain: Record<string, unknown>[], name: string): string | undefined {
  for (const value of chain) {
    for (const source of [value.headers, value.responseHeaders, isRecord(value.response) ? value.response.headers : undefined]) {
      if (source instanceof Headers) {
        const found = source.get(name);
        if (found !== null) return found;
      } else if (isRecord(source)) {
        const entry = Object.entries(source).find(([key]) => key.toLowerCase() === name);
        if (entry && typeof entry[1] === 'string') return entry[1];
      }
    }
  }
  return undefined;
}

function isTransient(error: unknown, chain: Record<string, unknown>[], advice?: ModelRetryAdvice): boolean {
  if (advice?.normalized?.isAbort === true
    || PERMANENT_CODES.has(String(advice?.normalized?.errorCode).toLowerCase())) return false;
  if (chain.some((value) => {
    const body = isRecord(value.error) ? value.error : {};
    return [value.code, value.type, body.code, body.type].some((code) =>
      typeof code === 'string' && PERMANENT_CODES.has(code.toLowerCase()));
  })) return false;
  if (chain.some((value) => [
    'AbortError', 'APIUserAbortError', 'ModelRefusalError', 'ModelBehaviorError', 'UserError',
    'InputGuardrailTripwireTriggered', 'OutputGuardrailTripwireTriggered',
    'ToolInputGuardrailTripwireTriggered', 'ToolOutputGuardrailTripwireTriggered',
    'ZodError', 'SyntaxError', 'RangeError', 'ReferenceError',
  ].includes(String(value.name)) || (value.name === 'TypeError' && value.message !== 'fetch failed'))) return false;
  const status = chain.map((value) => value.status ?? value.statusCode).find((value) => typeof value === 'number')
    ?? advice?.normalized?.statusCode;
  if (typeof status === 'number' && !TRANSIENT_STATUSES.has(status)) return false;
  const retryHint = header(chain, 'x-should-retry')?.trim().toLowerCase();
  if (advice?.suggested === false || retryHint === 'false') return false;
  return error instanceof ModelTimeoutError || advice?.suggested === true
    || retryHint === 'true'
    || (typeof status === 'number' && TRANSIENT_STATUSES.has(status))
    || advice?.normalized?.isNetworkError === true
    || chain.some((value) => ['APIConnectionError', 'APIConnectionTimeoutError', 'FetchError'].includes(String(value.name))
      || NETWORK_CODES.has(String(value.code))
      || (value.name === 'TypeError' && value.message === 'fetch failed'));
}

function canReplay(request: ModelRequest, chain: Record<string, unknown>[], advice?: ModelRetryAdvice): boolean {
  const extra = request.modelSettings.providerData ?? {};
  // A Session is loaded into input; it is not a server-managed model conversation.
  if (request.conversationId || request.previousResponseId) return false;
  for (const body of [extra, extra.extra_body, extra.extraBody]) {
    if (body === undefined) continue;
    if (!isRecord(body)) return false;
    // Hidden prompt/provider-defined tools may have hosted side effects we cannot classify.
    if (body.conversation || body.conversation_id || body.previous_response_id || body.conversationId
      || body.previousResponseId || body.background || body.tools || body.prompt) return false;
  }
  if (request.prompt && !request.toolsExplicitlyProvided) return false;
  if (advice?.replaySafety === 'unsafe' || chain.some((value) => value.unsafeToReplay === true)) return false;
  return request.tools.every((tool) => tool.type === 'function' || isWebSearch(tool));
}

function assertDeadlineConfig({ timeoutsMs, initialBackoffMs, maxBackoffMs }: ModelDeadlineConfig): void {
  if (!timeoutsMs.length || timeoutsMs.length > 3
    || timeoutsMs.some((ms) => !Number.isFinite(ms) || ms <= 0 || ms > 2_147_483_647)
    || !Number.isFinite(initialBackoffMs) || initialBackoffMs < 0
    || !Number.isFinite(maxBackoffMs) || maxBackoffMs < 0 || maxBackoffMs > 2_000) {
    throw new RangeError('Model deadlines require one to three positive budgets and backoff bounded to 2000ms.');
  }
}

/** Shared safety/backoff for both SDK model-call signatures, not a second retry owner. */
async function waitForModelRetry(
  model: Model, request: ModelRequest, error: unknown, attempts: number,
  config: ModelDeadlineConfig, modelName: string | undefined, stream: boolean,
): Promise<void> {
  request.signal?.throwIfAborted();
  let advice: ModelRetryAdvice | undefined;
  if (model.getRetryAdvice) {
    try {
      advice = await withinDeadline(() => model.getRetryAdvice!({ request, error, attempt: attempts, stream }),
        2_000, request.signal);
    } catch (adviceError) {
      request.signal?.throwIfAborted();
      throw new ModelDeadlineExhaustedError(attempts, 'retry_advice_failed', adviceError);
    }
  }
  const chain: Record<string, unknown>[] = [];
  for (let value = error; isRecord(value) && !chain.includes(value) && chain.length < 8; value = value.cause) chain.push(value);
  if (!isTransient(error, chain, advice)) throw error;
  if (!canReplay(request, chain, advice) || (stream && advice?.responseStarted === true)) {
    throw new ModelDeadlineExhaustedError(attempts, 'unsafe_replay', error);
  }
  if (attempts === config.timeoutsMs.length) throw new ModelDeadlineExhaustedError(attempts, 'attempts_exhausted', error);
  const delays = [advice?.retryAfterMs, advice?.normalized?.retryAfterMs];
  const milliseconds = header(chain, 'retry-after-ms');
  if (milliseconds !== undefined) delays.push(Number(milliseconds));
  const afterHeader = header(chain, 'retry-after');
  if (afterHeader !== undefined) {
    const seconds = Number(afterHeader);
    delays.push(Number.isFinite(seconds) ? seconds * 1_000 : Date.parse(afterHeader) - Date.now());
  }
  const validDelays = delays.filter((ms): ms is number => typeof ms === 'number' && Number.isFinite(ms) && ms >= 0);
  const after = validDelays.length ? Math.max(...validDelays) : undefined;
  if (after !== undefined && after > config.maxBackoffMs) {
    throw new ModelDeadlineExhaustedError(attempts, 'retry_after_exceeds_budget', error);
  }
  const backoffMs = after ?? Math.min(config.maxBackoffMs, config.initialBackoffMs * 2 ** (attempts - 1));
  log('warn', 'model_deadline_retry', {
    model: modelName, attempt: attempts, timeoutMs: config.timeoutsMs[attempts - 1],
    nextTimeoutMs: config.timeoutsMs[attempts], backoffMs,
    errorName: error instanceof Error ? error.name : 'UnknownError',
  });
  if (backoffMs > 0) await delay(backoffMs, undefined, { signal: request.signal });
}

/** Retry only this pending model request; never restart Runner or completed tools. */
export async function getModelResponse(
  model: Model, request: ModelRequest, policy: ModelDeadlineConfig = modelDeadlineConfig, modelName?: string,
): Promise<ModelResponse> {
  const config = { ...policy, timeoutsMs: [...policy.timeoutsMs] };
  assertDeadlineConfig(config);
  for (let index = 0; ; index++) {
    request.signal?.throwIfAborted();
    try {
      return await withinDeadline((signal) => model.getResponse({ ...request, signal }), config.timeoutsMs[index], request.signal);
    } catch (error) {
      await waitForModelRetry(model, request, error, index + 1, config, modelName, false);
    }
  }
}

/** One total deadline per streamed attempt, including opening and all event reads. */
export async function* getModelStream(
  model: Model, request: ModelRequest, policy: ModelDeadlineConfig = modelDeadlineConfig, modelName?: string,
): AsyncIterable<StreamEvent> {
  const config = { ...policy, timeoutsMs: [...policy.timeoutsMs] };
  assertDeadlineConfig(config);
  for (let index = 0; ; index++) {
    request.signal?.throwIfAborted();
    const controller = new AbortController();
    let timer: ReturnType<typeof setTimeout> | undefined;
    let onAbort: (() => void) | undefined;
    const interrupted = new Promise<never>((_resolve, reject) => {
      onAbort = () => { reject(request.signal!.reason); controller.abort(request.signal!.reason); };
      request.signal?.addEventListener('abort', onAbort, { once: true });
      timer = setTimeout(() => {
        const error = new ModelTimeoutError({ timeoutMs: config.timeoutsMs[index] });
        reject(error);
        controller.abort(error);
      }, config.timeoutsMs[index]);
    });
    // A provider can synchronously abort/throw while creating its iterator.
    void interrupted.catch(() => undefined);
    let iterator: AsyncIterator<StreamEvent> | undefined;
    let emitted = false;
    let completed = false;
    let failure: unknown;
    try {
      // Starting the iterator may throw; its first next() also includes transport opening.
      iterator = model.getStreamedResponse({ ...request, signal: controller.signal })[Symbol.asyncIterator]();
      while (true) {
        const next = await Promise.race([Promise.resolve().then(() => {
          controller.signal.throwIfAborted();
          return iterator!.next();
        }), interrupted]);
        request.signal?.throwIfAborted();
        controller.signal.throwIfAborted();
        if (next.done) { completed = true; return; }
        emitted = true;
        // response_done is semantic completion. Do not wait on post-terminal cleanup.
        if (next.value.type === 'response_done') { completed = true; clearTimeout(timer); }
        yield next.value;
        if (completed) return;
      }
    } catch (error) {
      controller.abort(error);
      request.signal?.throwIfAborted();
      if (emitted) throw error; // Never repeat events already accepted by Runner.
      failure = error;
    } finally {
      clearTimeout(timer);
      if (onAbort) request.signal?.removeEventListener('abort', onAbort);
      if (!completed) controller.abort();
      // An iterator ignoring cancellation must not hold up recovery or caller close.
      void Promise.resolve().then(() => iterator?.return?.()).catch(() => undefined);
    }
    await waitForModelRetry(model, request, failure, index + 1, config, modelName, true);
  }
}

let openAIProvider: OpenAIProvider | undefined;

// The SDK requires getModel(); this is the only model-boundary wrapper.
export const modelDeadlineProvider: ModelProvider = {
  async getModel(modelName) {
    // Clone the configured client once, preserving its key, endpoint, headers and fetch.
    openAIProvider ??= new OpenAIProvider({
      openAIClient: getDefaultOpenAIClient()?.withOptions({ maxRetries: 0 }) ?? new OpenAI({ maxRetries: 0 }),
      useResponses: true,
      useResponsesWebSocket: false,
    });
    const model = await openAIProvider.getModel(modelName);
    const deadlineFor = (request: ModelRequest) => (request.tools.some(isWebSearch) ? webSearchDeadlineConfig : modelDeadlineConfig);
    return {
      supportsPromptModelSelection: model.supportsPromptModelSelection,
      getResponse: (request) => getModelResponse(model, request, deadlineFor(request), modelName),
      getStreamedResponse: (request) => getModelStream(model, request, deadlineFor(request), modelName),
      // Do not expose another SDK retry owner.
    };
  },
};
```

## 4. Sub-agent recovery when an orchestrator calls agents as tools (reference behavior)

When a nested run throws (for example `ModelDeadlineExhaustedError`), the SDK turns the error into plain error text as the tool output. The reference never lets that text reach the orchestrator model. Two native tool guardrails handle it (`src/agents/manager/specialists/flight.ts`):

1. **Output guardrail:** when the output does not match the sub-agent's output schema, replace it with a typed `partial` or `failure` result. The result is built from the tool calls that actually succeeded during this invocation, found by comparing the tool log against a baseline captured before the run.
2. **Input guardrail:** once the sub-agent has failed in this user turn, reject further calls with the same typed failure. Without this, the orchestrator could reopen the failed sub-agent and get a fresh 3-attempt budget each time. State is request-scoped (a `WeakMap` keyed by the context object plus a `requestId` check), so the next user turn starts clean.

```ts
interface InvocationBaseline { logLength: number; prediction: unknown }
interface TurnRecovery {
  requestId: FlightAppContext['requestId'];
  baselines: Map<string, InvocationBaseline>;
  failedOutput?: string;
}

// Private, request-local evidence only. No state from another user turn can disable the sub-agent.
const turnRecovery = new WeakMap<object, TurnRecovery>();
function recoveryFor(context: object): TurnRecovery {
  const appContext = getRequestState(context as FlightAppContext);
  let recovery = turnRecovery.get(context);
  if (!recovery || recovery.requestId !== appContext.requestId) {
    recovery = { requestId: appContext.requestId, baselines: new Map() };
    turnRecovery.set(context, recovery);
  }
  return recovery;
}

flightAgentAsTool.inputGuardrails = [{
  type: 'tool_input',
  name: 'flight_recovery_turn_boundary',
  async run({ context, toolCall }) {
    const recovery = recoveryFor(context.context as object);
    if (recovery.failedOutput) {
      return { behavior: { type: 'rejectContent', message: recovery.failedOutput } };
    }
    const appContext = getRequestState(context.context as FlightAppContext);
    recovery.baselines.set(toolCall.callId, {
      logLength: appContext.toolCallLog.length,
      prediction: appContext.flight.lastPricePrediction,
    });
    return { behavior: { type: 'allow' } };
  },
}];

flightAgentAsTool.outputGuardrails = [{
  type: 'tool_output',
  name: 'flight_recovery_feedback',
  async run({ context, toolCall, output }) {
    const recovery = recoveryFor(context.context as object);
    const baseline = recovery.baselines.get(toolCall.callId);
    recovery.baselines.delete(toolCall.callId);
    let parsed: unknown;
    try { parsed = typeof output === 'string' ? JSON.parse(output) : output; } catch { /* Native failure text. */ }
    if (flightManagerOutputSchema.safeParse(parsed).success) {
      return { behavior: { type: 'allow' } };
    }
    recovery.failedOutput = interruptedFeedback(
      getRequestState(context.context as FlightAppContext), baseline,
    );
    return { behavior: { type: 'rejectContent', message: recovery.failedOutput } };
  },
}];
```

`interruptedFeedback` reads the tool-log entries added after `baseline.logLength` that have `ok: true`. It returns `status: 'partial'` with one finding per completed operation (search done, filter applied, and so on), or `status: 'failure'` when nothing completed. It always returns schema-valid JSON. The orchestrator prompt says: "distinguish completed, partial, missing-input and failed outcomes… Do not invent recovery work or repeat the same unchanged task."

A simpler sub-agent with no partial work uses only the output guardrail, which replaces any non-schema output with a fixed typed failure (`trip_v2_typed_feedback` in `src/agents/manager/specialists/trip-planner-v2.ts`).

## 5. Tool failures the model may repair (reference behavior; this is not a transport retry)

Tools return typed failures instead of throwing (`src/agents/flight/tools/recovery.ts`), so the model can make one corrected attempt:

```ts
{ ok: false, code, message, recovery: { kind: 'input'|'temporary'|'unavailable'|'internal',
  retrySafe, stateChanged, fieldIssues?: [{ path, problem, acceptedValue?, constraint? }], requiredState? } }
```

- `retrySafe` defaults to true only for `kind: 'input'`. Execution errors become `TOOL_EXECUTION_ERROR`, `kind: 'internal'`, `retrySafe: false`.
- Each failure gets a fingerprint: `sha256(JSON(stable-sorted {toolName, code, input}))`, truncated to 16 hex characters. If the same fingerprint already failed in this `requestId`, the code sets `retrySafe = false` and appends "This exact failed payload was already attempted; do not retry it again."
- The tool log records `recoveryDecision: 'pending_model_decision'`. A later success of the same tool marks it `'retry_succeeded'`.
- The sub-agent prompt rule: "Retry in this run only when recovery.retrySafe=true and recovery.stateChanged=false. The retry payload must differ from the failed payload. Never retry the same tool/error/payload fingerprint more than once. Make at most two recovery retries across the complete user turn."
- A non-critical final tool (suggested follow-up questions) allows one corrected attempt. A second rejection withdraws it without touching completed results.

```ts
export function recordFlightToolFailure({ appContext, toolName, failure, input }) {
  const fingerprint = createRecoveryFingerprint(toolName, failure.code, input);
  const requestId = appContext.requestId || null;
  const priorAttempts = appContext.toolCallLog.filter((entry) =>
    entry.tool === toolName && entry.ok === false &&
    entry.requestId === requestId && entry.recoveryFingerprint === fingerprint).length;
  if (priorAttempts >= 1) {
    failure.recovery.retrySafe = false;
    failure.message = `${failure.message} This exact failed payload was already attempted; do not retry it again.`;
  }
  appContext.toolCallLog.push({ tool: toolName, requestId, ok: false, code: failure.code,
    recovery: failure.recovery, recoveryFingerprint: fingerprint,
    recoveryDecision: 'pending_model_decision', retryCount: priorAttempts });
  return failure;
}
```

## 6. HTTP/SSE turn handling (reference behavior)

- **One turn per chat at a time.** `store.acquireTurn(chatId)` returns null when a turn is already running, and the endpoint answers `409 CHAT_BUSY`. This stops a double-submit from creating duplicate turns and duplicate tool runs.
- **Client disconnect cancels the run.** An `AbortController` is aborted on `response.once('close')` unless the turn already finished. Its signal goes to `runner.run({ signal })` and reaches every model attempt and backoff.
- **No partial text reaches the client.** The server sends `chat.created`, `conversation.ready`, `turn.started`, then **one** `delta` containing the whole final sanitized answer, then `done` (or `error`). Partial and duplicate chunks are therefore impossible, and there is nothing to resume.
- **Failure handling.** The turn is saved as `failed` or `aborted`. State from completed flight tools is kept, while unseen trip-plan changes are reverted. A generic error event is sent ("The request could not be completed. Please try again."). The server never resubmits automatically; the user retries.
- **Cancelled-turn rollback.** The SDK session saves the user message and finished steps even when a run is cancelled. The reference pops those items so the next turn's history does not show changes that were never kept:

```ts
const MAX_CANCELLED_TURN_ITEMS = 100;
async function removeCancelledTurn(session: Session): Promise<number> {
  const [newest] = (await session.getItems(1)) as { type?: string; role?: string }[];
  if (!newest || (newest.type === 'message' && newest.role === 'assistant')) return 0;
  let removed = 0;
  while (removed < MAX_CANCELLED_TURN_ITEMS) {
    const item = (await session.popItem()) as { role?: string } | undefined;
    if (!item) break;
    removed += 1;
    if (item.role === 'user') break;
  }
  return removed;
}
// in catch: if (aborted && runStarted && session) await removeCancelledTurn(session).catch(logWarn);
```

- **SSE writer.** It sets `Content-Type: text/event-stream`, `Cache-Control: no-cache, no-transform`, and `X-Accel-Buffering: no`. It writes an incrementing `id:` per event and a `: heartbeat` comment every 15 s. `send()` returns false once the response is closed or destroyed.

If our production API forwards token deltas to the client, the rule "never replay a stream after its first event" (Section 1) is what guarantees no duplicate chunks. Do not build client-side resume unless I ask for it.

## 7. Edge cases: each must hold, with one test each

Use fake `Model` objects; no network. Shrink the deadlines in tests (for example `[50, 70, 90]` ms, backoff 0).

| Case | Required behavior |
|---|---|
| Transient 503 twice, then success | 3 calls, success returned |
| 400 / 401 / 403 / 429 + `insufficient_quota` / refusal / `TypeError` / `AbortError` | 1 call, original error rethrown |
| `Retry-After: 1000` (seconds) or `retry-after-ms: 1000000` | 1 call, `retry_after_exceeds_budget` |
| `conversationId`, `previousResponseId`, hosted MCP tool, stored prompt, `providerData.extra_body.{conversation,background,tools,prompt}` | 1 call, `unsafe_replay` |
| Provider advice `replaySafety: 'unsafe'` or error `unsafeToReplay: true` | 1 call, `unsafe_replay` |
| `getRetryAdvice` throws or hangs | `retry_advice_failed` (bounded to 2 s) |
| Three attempts that never settle | `attempts_exhausted` after exactly 3 calls, no hang |
| Config array mutated during the first attempt | still exactly 3 attempts |
| Second model request after a successful tool | starts again at the first deadline |
| Client abort during backoff | rejects within milliseconds; no second call |
| Client abort while the classifier hangs | rejects with the abort reason |
| Stream emits chunks slowly past the deadline | `ModelTimeoutError` at the first budget; chunks did not extend it; no replay |
| Stream fails after 1+ events | 1 call; error rethrown; no duplicate events |
| Stream fails before its first event | retried with identical input (assert the serialized requests are equal) |
| `response_done` followed by a hanging `next()` / `return()` | returns immediately, `return()` called once, no timeout fired |
| Late tool-call proposal from an abandoned attempt | ignored; the tool runs exactly once |
| HTTP client | exactly 1 `fetch` per attempt (hidden retries off); shared client's `maxRetries` unchanged |
| Session history | retries do not reload or duplicate session writes |
| Sub-agent exhausts in a turn | orchestrator receives typed `partial` feedback containing the completed work; reopening in the same turn is rejected; the next user turn works |
| Same failing tool payload sent twice | second failure has `retrySafe: false` |

Reference tests to mirror: `tests/unit/model-deadline.test.ts`, `tests/unit/model-stream-deadline.test.ts`, `tests/integration/manager-model-deadline.test.ts`, `tests/integration/manager-stream-deadline.test.ts`.

## 8. Recommended improvements (not in the reference; ask before implementing)

1. **A turn-level budget.** The worst case for one model request is about 151.5 s (25 + 0.5 + 50 + 1 + 75), and a turn makes several model requests (orchestrator steps plus sub-agent steps). Nothing caps the whole turn. Option: `AbortSignal.any([clientSignal, AbortSignal.timeout(TURN_BUDGET_MS)])` passed as the run `signal`.
2. **Backoff jitter.** The reference uses fixed 500 ms and 1 s waits. With many concurrent users behind one rate limit, add full jitter, keeping the 2 s cap.
3. **A visible "retrying" status.** The reference client already handles an SSE `status: 'retrying'` event, but the server never sends it. If we want it, emit it from the retry log point through a request-scoped callback, without adding a new abstraction.
4. **Idempotency for side-effecting tools.** The reference tools are read-only, so it needs none. If our production tools write (bookings, payments), give each tool call an idempotency key derived from `requestId + callId`. Transport retries are safe by construction, but the orchestrator model can still choose to call a tool twice.
5. **Metrics.** Count retries by `reason` and `errorName`, and alert on `attempts_exhausted` and `unsafe_replay` rates.

## 9. Do not

- Do not leave the HTTP client's default retries, SDK `modelSettings.retry`, or agent-level `timeoutMs` active alongside this layer.
- Do not re-run `runner.run(...)` or the whole user turn after a failure.
- Do not approve unsafe replay for timeouts. (The reference has a separate standalone path, `src/agents/flight/config.ts` with `maxRetries: 1`, a 20 s `timeoutMs`, and `approveUnsafeReplay` on timeout. It is **not** the live chat path. Do not copy it.)
- Do not retry a stream after its first event, and do not try to stitch partial text together.
- Do not forward SDK error text or stack traces to the orchestrator model or to the client.
