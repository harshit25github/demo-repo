Create a **GET API** to retrieve records from our existing `Olli_Request` table.

### Requirements

1. Accept optional query parameters:

   - `chatId`
   - `requestId`
   - Both together

2. Fetch matching records from `Request`:

   - Only `chatId` → All records for that chat.
   - Only `requestId` → Records for that request.
   - Both → Records matching both identifiers.

3. Return all relevant stored fields in a structured JSON response.

4. Handle missing parameters, no records found, and database errors properly.

5. **No application authentication or JWT authorization is required** for this endpoint.

6. Inspect the table for sensitive data and ensure credentials or secrets are not publicly exposed.

### Implementation

- Follow our existing API/controller/service patterns.
- Reuse the existing database connection and queries.
- Keep implementation simple without unnecessary abstractions.
- Add the endpoint to Swagger and test all filtering scenarios.
- Do not modify the existing logging or table structure.

**Goal:** Provide a simple API to inspect `Olli_Request` logs using `chatId`, `requestId`, or both.

Implement and verify the API end-to-end.
