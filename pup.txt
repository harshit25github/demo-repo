Task:
Fix agent configuration sync for all existing and future apps/services.

Context:
We have multiple app/service strategies like:
- default
- OpenAI
- Gemini

Each strategy has agent configuration, including:
- agents used
- models
- prompts
- gateway/orchestrator mapping
- agent mappings

Issue:
Recent changes are only reflected for newly created apps/services.
Older apps/services still have old agent configuration.

Required Behavior:
The latest active agent configuration for a strategy should be reflected across:
- apps created earlier
- apps created now
- apps created in the future

If the current agent configuration is updated, all apps under that strategy should use the latest configuration.

Example:
If current OpenAI strategy uses:
- Flight Agent
- Policy Agent
- Trip Planner Agent

Then every app using OpenAI strategy should show/use only these agents, even older apps.

Required Work:
1. Identify the source of truth for active agent configuration per strategy.
2. Check why old apps are not getting updated.
3. Fix the update flow so config changes apply to existing apps also.
4. Add backfill/migration logic if needed to update older app records.
5. Ensure future app creation uses the same latest config.
6. Ensure removed agents are unlinked from old apps.
7. Ensure updated models/prompts/agent mappings are reflected everywhere.

Please Check:
- strategy-level config tables
- app-level config tables
- app-to-agent mapping
- gateway-to-agent mapping
- model update logic
- prompt update logic
- old/stale mappings
- cache issues
- retrieval API by App ID

Expected Behavior:
- Updating strategy agent config updates all apps using that strategy.
- Old apps should not keep outdated state.
- New apps should use latest strategy config.
- Removed agents should disappear from all related apps.
- Updated models should reflect for all related apps.
- App ID retrieval should always show the latest active config.

Acceptance Criteria:
- Existing apps reflect latest strategy config.
- New apps reflect latest strategy config.
- Model updates apply to old and new apps.
- Agent mapping updates apply to old and new apps.
- Removed agents like Hotel do not appear unless part of current config.
- Add tests for:
  - updating strategy config
  - checking old app config
  - creating new app after update
  - removing an agent
  - updating model
  - fetching agents/prompts by App ID
