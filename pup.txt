Profanity filter
Detects and either blocks, sanitizes, or flags offensive language using a mix of curated word lists and ML classifiers, keeping conversations safe and compliant.
(Useful for moderation, tone control, and generating user-facing warnings or sanitized outputs.)

Embedding generator
Converts text into numeric vectors (embeddings) so you can do semantic search, similarity matching, and clustering across documents or messages.
(Powers relevance ranking, recommendations, and fast retrieval for RAG workflows.)

LLM integration
Orchestrates calls to one or more language models (chat/completion + tooling), handling prompts, streaming, retries, and tool-calls for actions like DB queries or API requests.
(Provides conversational intelligence, action execution, and multi-step reasoning for your app.)

Token summarisation
Compresses long conversations or documents into concise summaries (or extracts important tokens/segments) to save context-window tokens and reduce API cost.
(Helps keep prompts within model limits, improves response relevance, and lowers usage cost.)

System prompt creation
Builds reusable, structured system prompts (with persona, rules, and examples) and supports dynamic insertion of context variables to reliably steer model behavior.
(Ensures consistent assistant persona, safety constraints, and predictable outputs across sessions.)
