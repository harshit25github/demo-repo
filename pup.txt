For the Gurgaon to Bangalore flight search, the issue is happening because the Intelli Suggest API is not resolving Gurgaon to the expected nearest airport/location.

Instead of identifying Delhi as the nearest valid airport, the API is returning CDR — Chadron, Nebraska, United States. Because of this incorrect origin mapping, the search key is getting generated, but no valid contracts/flights are available for Bangalore on 7/10 or even for alternate nearby dates.

So the main issue is with the location inference from the suggest API, where the user’s origin is not being mapped to the correct nearest airport.
