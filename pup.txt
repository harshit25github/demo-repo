Task:
Update the Tripana agent image-fetching behavior.

Context:
Tripana agent uses a tool called `GetPlaceImagesBatch`.
This tool accepts an array of selected destinations/locations and returns image URLs for those places.
The tool also has a fallback image URL when a real location image is not available.

Required Behavior:
- The agent must use only `GetPlaceImagesBatch` to fetch place/location images.
- The agent must never use web search, website scraping, browser tools, or any other external source to get images.
- If `GetPlaceImagesBatch` returns a valid image URL, use that.
- If `GetPlaceImagesBatch` fails or returns no image for a location, use the fallback URL provided by the same tool.
- Do not try to replace fallback images by searching the web.
- Do not extract image URLs from websites.

Implementation Requirement:
Add/modify the agent instructions so image sourcing is strictly limited to `GetPlaceImagesBatch`.

Acceptance Criteria:
- For every destination image, the source must come from `GetPlaceImagesBatch`.
- When fallback is returned, the agent should use the fallback as-is.
- No web search or external image lookup should happen for place images.
- Add tests to verify that fallback images do not trigger web search or scraping.
