Improve the existing **human handoff / soft handoff guardrail**. Do not redesign the overall flow.

### Expected behavior

We have two stages:

1. **First explicit human-agent request → Soft Handoff**

   * Acknowledge the request.
   * Follow the existing soft-handoff script/process.
   * Do not immediately perform the hard handoff.

2. **User asks for a human agent again → Hard Handoff**

   * Detect that the user has already requested human help earlier.
   * If they repeat/persist with the request, trigger the actual human handoff.

### Main issue

The second request is sometimes not detected correctly, especially when the user uses short, informal, or different wording.

Strengthen detection using **current message + conversation context + existing handoff state**, not keyword matching alone.

Treat messages like these as the same human-handoff intent when context supports it:

* `agent`
* `connect me`
* `human`
* `real person`
* `talk to someone`
* `still want agent`
* `no, connect me`
* `agent please`
* `I need someone`
* `can I talk to them`
* `just transfer me`

Important:

* Distinguish **human-agent requests** from requests referring to an AI/travel agent.
* The second request does not need to use the same wording as the first.
* If soft handoff has already happened and the user clearly persists, perform hard handoff.
* Do not reset the decision just because the wording changed.
* Do not trigger on vague mentions of the word `agent` when human intent is not clear.

Use an internal decision flow:

`Understand intent → Check prior handoff state → Detect persistence → Soft or Hard Handoff`

Review the current prompt/state handling and fix only what is needed to make repeated human-handoff requests reliable.

Also add tests covering short/lazy multi-turn inputs such as:

`agent` → soft handoff → `yes agent` → hard handoff

`talk to someone` → soft handoff → `no connect me` → hard handoff

`chat with travel agent about flights` → should NOT automatically mean human handoff unless context clearly indicates a human.

Keep the changes concise and preserve the existing handoff business rules.
