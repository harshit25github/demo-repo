

1. In SQL, which clause filters rows before any grouping happens?
   A) HAVING
   B) WHERE
   C) GROUP BY
   D) ORDER BY
   Answer: B

2. What does a PRIMARY KEY guarantee?
   A) Values can repeat
   B) Values can be NULL
   C) Values are unique and NOT NULL
   D) It points to another table
   Answer: C

3. Which SQL join returns only the rows that match in both tables?
   A) LEFT JOIN
   B) RIGHT JOIN
   C) FULL OUTER JOIN
   D) INNER JOIN
   Answer: D

4. You want rows from table A that have no match in table B on column id. Which is correct?
   A) SELECT \* FROM A INNER JOIN B ON A.id = B.id;
   B) SELECT \* FROM A LEFT JOIN B ON A.id = B.id WHERE B.id IS NULL;
   C) SELECT \* FROM A RIGHT JOIN B ON A.id = B.id WHERE A.id IS NULL;
   D) SELECT \* FROM A FULL JOIN B ON A.id = B.id;
   Answer: B

5. In a NoSQL document database, which statement is generally true?
   A) All documents must have identical fields
   B) Schema is flexible; documents can have different fields
   C) Cross-collection joins are built-in like SQL
   D) Only key–value pairs are allowed
   Answer: B

6. Which protocol is connection-oriented and ensures reliable delivery?
   A) UDP
   B) ICMP
   C) TCP
   D) ARP
   Answer: C

7. What does DNS do on the network?
   A) Encrypts traffic between client and server
   B) Maps domain names to IP addresses
   C) Assigns MAC addresses to devices
   D) Blocks suspicious packets at the edge
   Answer: B

8. For IP address 192.168.1.130/26, which range is the correct subnet?
   A) 192.168.1.0 – 192.168.1.63
   B) 192.168.1.64 – 192.168.1.127
   C) 192.168.1.128 – 192.168.1.191
   D) 192.168.1.192 – 192.168.1.255
   Answer: C

9. Which statement about processes and threads is correct?
   A) Threads in a process have separate address spaces
   B) Threads share the same address space but have their own stacks
   C) Processes share the same address space by default
   D) Threads cannot run in parallel on multi-core CPUs
   Answer: B

10. Which is NOT one of the standard necessary conditions for deadlock?
    A) Mutual exclusion
    B) Hold and wait
    C) No preemption
    D) Preemption
    Answer: D
