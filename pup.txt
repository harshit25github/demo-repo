The external links are coming because the trip planner needs to use web search for real-time information like nearby hotels, places, and travel suggestions. Since we are using OpenAI-hosted web search, we cannot directly control or filter the source links returned by the tool.

From our side, the agent will not recommend or promote any external website for bookings. The web search is only used to gather information needed for better trip suggestions.

Filtering this on the server side is not ideal because responses are streamed through SSE in chunks. We would need to buffer and combine chunks to detect links, which would impact the streaming experience.

So the better approach is to handle link hiding on the client side, as we are already doing on dev.cheapoAI.com.
