## 1. Git Branch Preparation — Mandatory First Step

1. Inspect the current Git branch and working-tree status.
2. Commit existing changes on the current branch, ensuring no untracked or modified work is lost. Inspect changes first and avoid committing secrets or generated files.
3. Create a new dedicated feature branch from the updated current branch, such as `feature/nexus-ui-enhancement`.
4. Perform **all UI enhancement work exclusively on the new branch**.
5. Do not merge changes into the original branch.

First, thoroughly explore the entire Nexus Next.js application and understand the existing user journey.

Review:

- Chat interface and message rendering.
- Flight search results and flight cards.
- Hotel search results and hotel cards.
- Trip Planner itinerary presentation.
- Suggested questions and CTA chips.
- Search/filter interactions.

Study modern AI chat and travel-booking UI/UX patterns and determine which approaches are practical for our existing capabilities.

## 3. Redesign the Complete User Experience

Propose and implement a cohesive design system with modern components, consistent spacing, typography, colors, icons, and subtle animations.

Explore the best placement and behavior of these components:

**A. AI Chat Interface**
- Clean, premium conversational experience.
- Clear separation between user and AI messages.
- Better message formatting, acknowledgements, and visual hierarchy.
- Intelligent suggested-question/CTA presentation.
- Modern composer/input experience.
- Smooth streaming and scrolling behavior.

**B. Flight Cards**
- Beautiful, compact, easy-to-compare flight cards.
- Clear visibility of price, airline, departure/arrival times, stops, duration, baggage, and relevant available details.
- Better card selection, expansion, and interaction.
- Appropriate layout for multiple search results.
- Avoid clutter and unnecessary information.

**C. Hotel Cards**
- Visually appealing hotel cards with meaningful images where already available.
- Clear hotel name, location, price, rating, amenities, and other existing information.
- Better hotel comparison and selection.
- Responsive layouts and intuitive interactions.

**D. Trip Planner**
- Present itineraries in a structured, visually engaging format.
- Explore timelines, day-wise itinerary cards, and expandable details.
- Ensure users can understand travel plans without reading unnecessarily long chat responses.

**E. Cross-Agent Experience**
- Determine how flight results, hotel results, and itineraries should coexist in the interface.
- Explore whether a contextual side panel, dedicated result area, tabs, or hybrid chat layout would improve usability.
- Ensure users can switch between discussing their trip and exploring results without losing context.

Do not blindly implement these ideas. Evaluate the existing Next.js architecture and choose the most practical and intuitive product design.

## 4. Improve Next.js Performance and Smoothness

Some interactions currently feel laggy.

Investigate and improve:

- Unnecessary React re-renders.
- Expensive card rendering.
- Streaming UI updates.
- Loading and transition states.
- Layout shifts and flickering.
- Auto-scroll behavior.
- Switching between flight/hotel result views.
- Rendering large result lists.
- Next.js client/server component boundaries, where applicable.
- Image loading and rendering performance.
- Unnecessary client-side JavaScript and bundle size.

Use appropriate Next.js and React optimization techniques, such as component memoization, dynamic imports, image optimization, virtualization, skeletons, and progressive rendering **only where justified**.

The interface should feel responsive even while the backend is processing requests.

Do not hide failures or show misleading completion states.

## 5. Responsive & Interactive Design

Ensure the experience works well across:

- Desktop.
- Tablet.
- Mobile.

Use accessible interactions, intuitive navigation, appropriate animations, and consistent visual feedback.

Avoid excessive animations, unnecessary complexity, and over-engineered component structures.
