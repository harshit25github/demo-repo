Thoroughly investigate and fix our **Post-Booking Decision API Guardrail**, which is failing to recognize even explicit existing-booking requests.

### Core Requirement

**Any request explicitly related to an existing booking must be classified as post-booking, regardless of `hasUpcomingTrips` being true or false.**

Examples:
- "I need help with my existing booking."
- "I want to modify my reservation."
- "Can you check my booking details?"
- "I booked from another account."
- "I need assistance with a previous reservation."

**Important:** `hasUpcomingTrips = false` must never override clear post-booking intent. Booking ownership and availability are separate from intent classification.

### Your Task

1. Thoroughly inspect the current Decision API policy, prompts, confidence handling, and context hydration.
2. Identify why explicit existing-booking requests are being misclassified.
3. Improve the Decision API's semantic understanding rather than adding isolated keyword-based rules.
4. Ensure clear post-booking intent triggers the Post-Booking Guardrail, while genuinely ambiguous queries still receive appropriate clarification.
5. Build challenging test cases covering explicit, implicit, multilingual, multi-turn, and conflicting-context requests.
6. Implement the necessary fixes and repeatedly test until classification is consistent, without breaking existing pre-booking behavior.

**Important:**
- Prioritize a robust, generalizable solution over quick prompt patches.
- Avoid regex, hardcoded keyword lists, and unnecessary wrappers.
- Validate the actual Decision API outputs and final routing, not just prompt expectations.
- Keep changes focused on the Post-Booking Guardrail.

**Goal:** Make the Decision API reliably recognize any genuine existing-booking intent, even when the user has no upcoming trips associated with their current account.

**Put substantial effort into root-cause investigation, implementation, and comprehensive regression testing.** Provide a concise report of the failures found, fixes made, and before/after test results.
