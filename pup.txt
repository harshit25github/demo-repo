Plan smarter pre-search CTAs / “You might ask” questions for Flight Agent.

Do not implement yet. First inspect the current CTA/suggested-question flow and propose the best design.

## Goal

Currently CTAs are mainly generated after a flight search. We also want useful CTAs before a search is possible, based on whatever travel context is already known.

Most important rule:

**Once the user selects/uses a CTA, that CTA or the same intent must not be suggested again in the conversation.**

Avoid exact and semantic repetition.

## Required scenarios

### 1. Departure + Arrival known, travel date missing

Example:
`DEL → DXB`, no date.

Possible CTAs:
- Cheapest this week
- Cheapest next month
- Cheapest in the next 3 months

Do NOT use:
- “Earliest flight from origin to destination”

### 2. Only Departure location known

Example:
`From Delhi`, but no arrival location/date.

Possible discovery CTAs:
- Cheapest beach destination from Delhi
- Cheapest international destination from Delhi
- Weekend getaway from Delhi

These should help the user discover what they can do next.

## Also explore other useful states

Plan intelligent CTAs for cases such as:

- only arrival location known
- departure + date known, arrival missing
- arrival + date known, departure missing
- departure + arrival + flexible/month-level date known
- departure + arrival + exact date known but search not yet initiated
- complete search context available
- price prediction completed and user can proceed to flight search
- completely empty flight context

Do not force CTAs where they do not add value.

## CTA generation rules

CTAs should be:
- short and mobile-friendly
- from the user’s perspective
- actionable
- based only on currently available context
- relevant to the next logical step
- non-repetitive
- natural, not robotic

Track previously selected/generated CTA intent so already-used actions are not suggested again.

Example:
If user already selected:
`Cheapest next month`

Do not later generate:
- “Find cheapest flights next month”
- “Show lowest fares next month”

Treat these as the same CTA intent.

- how to generate CTAs before and after flight search
