Add suggested questions flow for Policy Agent.

Goal:
Implement the same suggested questions pattern already used in Flight Agent and Trip Planner Agent for Policy Agent.

Reference:
Check existing implementation in either:
- Flight Agent suggested questions tool
- Trip Planner suggested questions tool

Follow the same architecture and style.

## Required changes

### 1. Add Policy Agent suggested questions tool

Create a tool like:

`update_policy_suggested_questions`

Purpose:
- Policy Agent generates useful follow-up questions.
- Tool only validates and stores them.
- Tool should not generate questions by itself.

Expected storage:
```ts
context.policy.suggestedQuestions = [...]
````

Use the existing context pattern used by Flight/Trip Planner.

### 2. Update Policy Agent prompt

Update Policy Agent prompt so it always calls this tool at the end of every Policy Agent turn.

The questions should be:

* from the user’s perspective
* short and mobile-friendly
* related to policy/help topics only
* context-aware
* not repetitive or stale

Good examples:

* "What is the cancellation policy?"
* "Can I get a refund for this ticket?"
* "What baggage allowance applies?"
* "Are there any change fees?"
* "What happens if I miss my flight?"

Avoid:

* unrelated trip planning questions
* hotels/cars/commute questions
* booking/payment completion questions
* generic repeated questions

### 3. Summary Extractor integration

Currently, after extractor runs, Flight and Trip Planner override extractor-generated suggested questions with their own tool-generated questions.

Apply the same logic for Policy Agent.

Required behavior:

```ts
if (lastAgent === "PolicyAgent") {
  summaryContext.suggestedQuestions = context.policy.suggestedQuestions;
}
```

Do not remove existing Flight/Trip Planner logic.

### 4. Tests

Add tests for:

1. Policy Agent answers baggage query → updates policy suggested questions.
2. Policy Agent answers cancellation/refund query → updates relevant questions.
3. Extractor generates its own questions → final summaryContext uses Policy Agent tool questions instead.
4. No stale Flight/Trip Planner questions remain after Policy Agent turn.
5. Tool is called at the end of Policy Agent response.

* Add Policy Agent suggested questions tool.
