Plan Post-Booking Guardrail improvements to avoid false tripwires on pre-booking/page-assistance queries.

Do not implement yet. First inspect the current Gateway, CheapOair Pages Agent, and Post-Booking Guardrail behavior.

## Problem

The Post-Booking Guardrail is incorrectly tripwiring some valid pre-booking queries.

Example:
“How do I view seat selection options for my flight?”

This can be a pre-booking/page-assistance query and should be handled by the CheapOair Pages Agent, not treated as post-booking.

## What to inspect

1. Gateway routing
- How Gateway decides between:
  - CheapOair Pages Agent
  - Post-Booking Guardrail
  - other agents
- What routing rules currently exist for seat selection, review page, payment page, booking flow, etc.

2. CheapOair Pages Agent
- Review its prompt and responsibilities.
- List the pre-booking/page-related intents it should handle.
- Identify examples that may currently overlap with post-booking detection.

3. Post-Booking Guardrail
- Review current prompt/rules.
- Identify why generic booking-related words like:
  - seat
  - booking
  - ticket
  - flight
  - review
  - confirmation
may incorrectly trigger post-booking.

## Required behavior

Post-booking should tripwire only when there is clear evidence of an existing completed booking or a request to manage an existing booking.

Examples of true post-booking:
- booking/PNR/confirmation/order already exists
- cancel my booking
- change my booked flight
- refund my ticket
- manage existing reservation
- baggage/change/cancellation question tied to an existing booking

Examples that should NOT tripwire:
- how do I select a seat?
- where can I choose seats?
- what happens on the review page?
- how do I continue to payment?
- can I add baggage before booking?
- how do I pick a fare?
- seat-selection/page-navigation questions before booking completion

## Important principle

Do not classify based only on keywords like “seat”, “booking”, “ticket”, or “flight”.

Use intent and booking state:
- pre-booking/page assistance → CheapOair Pages Agent
- existing-booking management → Post-Booking Guardrail

If booking state is ambiguous, prefer normal pre-booking routing unless there is clear evidence of an existing booking.
