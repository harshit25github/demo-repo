## Midterm Review — Jan to June 2026

### 1. Achievement Against Goals and KPIs

During Jan–June 2026, I worked on building and enhancing the agentic backend system for the pre-booking travel experience. The goal was to support users with trip planning, flight-related queries, policy information, page-related queries, and contextual travel assistance through an AI-powered workflow.

Key achievements:

* Built a multi-agent backend system to support trip planning, flight assistance, policy queries, and page-level user queries.
* Integrated app-level user context with the AI agent flow to improve continuity between the app and chatbot experience.
* Enabled strong context-building and memory handling so the agent can understand user preferences, app activity, flight search criteria, filters, and previous interactions.
* Improved personalization by using user activity and search behavior to provide more relevant responses instead of restarting the conversation from scratch.
* Worked on advanced flight search handling, multi-filter support, and contextual search continuation between the listing page and AI workflow.
* Implemented backend-level controls such as rate limiting, guardrails, routing, and human handoff support to make the system more reliable and controlled.
