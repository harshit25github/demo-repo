### 1. Centralized Intent Understanding

Explore whether the Manager should own high-level pre-booking vs post-booking intent classification, rather than relying entirely on individual specialist agents.

Review our completed Gateway implementation, Guardian Decision API, and existing Manager routing.

Use these contextual signals intelligently:
- `hasUpcomingTrips` — Whether the user has upcoming bookings.
- `searchKey` — Whether an active flight search exists.

**Examples:**
- "Baggage" → Clarify whether the user wants to add baggage to an existing booking or check baggage policies.
- "Cancellation" → Clarify whether the user wants to cancel a booking or understand cancellation policies.
- "Baggage allowance" after a flight search → Consider the active search context.
- "Cancel my existing booking" → Recognize explicit post-booking intent.

Evaluate Manager-level, Guardian-level, and hybrid approaches for accuracy, latency, and future scalability across Flight, Trip Planner, and Hotel Agents.

Preserve necessary post-booking guardrails and avoid unnecessary specialist invocations.

### 2. Manager-Owned Suggested Questions Tool

Currently, specialist agents generate fresh suggested questions whenever they are invoked. However, when the Manager handles a query independently, no fresh suggested questions are generated.

**Required behavior:**

- **Specialist invoked:** Continue using the specialist-generated suggested questions.
- **No specialist invoked:** The Manager must invoke its own `update_suggested_questions` tool and generate fresh, context-aware suggestions.
- Never reuse stale suggested questions from previous turns.
- Never invoke Flight Agent or Trip Planner solely to generate suggested questions.
- Preserve our existing `summary.suggestedQuestions` hydration contract.
- Avoid duplicate tool invocations or unnecessary additional LLM calls.

**Example 1 — Ambiguous cancellation**

User: "Cancellation"

Manager asks: "Do you want to cancel an existing booking or check cancellation policies?"

Expected suggested questions:
- Cancel my existing booking
- Check cancellation policies for a new trip

**Example 2 — Ambiguous baggage**

User: "Baggage"

Expected suggested questions:
- Add baggage to my existing booking
- Check baggage allowances for a flight

**Example 3 — Trip Planner Zoom-In**

User: "Explain Day 2 in more detail."

Manager answers using existing itinerary context without invoking Trip Planner.

Expected suggested questions:
- Show Day 2 travel timings
- Find restaurants near Day 2 attractions
- Make Day 2 more relaxed

The suggested questions must be generated fresh using the current conversation, not hardcoded responses.
