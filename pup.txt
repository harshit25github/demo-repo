Implement a function that selects 5 flight contracts from the API response.

Rules:

1. Find all contracts that match the user’s exact search:
   - same origin
   - same destination
   - same travel date

2. Sort these exact-match contracts by price ascending.

3. Positions 1, 2, and 3 must always be filled with the 3 cheapest exact-match contracts.

4. For positions 4 and 5, consider only contracts that differ by:
   - airport code, or
   - travel date

5. A different-airport / different-date contract can be placed in position 4 or 5 only if its price is strictly lower than the cheapest exact-match contract.

6. If 2 such cheaper alternate contracts exist, place them in positions 4 and 5.

7. If only 1 such cheaper alternate contract exists, place it in position 4, and fill position 5 with the next cheapest exact-match contract.

8. If no such cheaper alternate contracts exist, fill positions 4 and 5 with the next cheapest exact-match contracts.

9. Always return exactly 5 contracts whenever at least 5 contracts are available in the input.

10. Add tags for every returned contract:
   - `isDifferentAirport`
   - `isDifferentDate`
   - `isAlternateContract`

Edge cases:
- If fewer than 3 exact-match contracts exist, use all available exact matches first, then fill remaining slots from the cheapest other contracts.
- If total input has fewer than 5 contracts, return all available contracts.

Important:
- Positions 1–3 should prioritize exact-match contracts only.
- Alternate contracts can appear only in positions 4 and 5.
- Do not move alternate contracts into the top 3.
