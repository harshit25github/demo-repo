Improve Trip Planner itinerary quality and formatting.

Scope:
- Trip Planner prompt
- itinerary response formatting rules
- mobile response quality rules

Do not modify unrelated agents/tools unless required.

## Problems to fix

1. Over-forcing morning/afternoon/evening blocks
Current prompt forces every block to have a unique activity, which creates illogical filler.

Examples of bad behavior:
- adding naps unnecessarily
- adding activities during arrival/departure when it does not make sense
- overpacking the itinerary just to fill all blocks

Required behavior:
- Do not force every morning/afternoon/evening block if it feels unnatural.
- Arrival/departure days can be lighter.
- Skip blocks that do not add real value.
- Never add naps unless user explicitly asks for rest/relaxed itinerary and it fits naturally.

2. Omit empty details properly
Each itinerary activity may include:
- place/activity line
- short description
- fun/practical fact

If any detail is not available or not useful, omit it completely.

Do not generate:
- empty bullets
- empty lists
- placeholder text
- blank “fact” sections
- meaningless filler

3. Remove bold formatting inside itinerary blocks
Currently the place/activity name is sometimes bold.

Required:
- In morning/afternoon/evening activity lists, do not bold place names or activity names.
- Keep each line simple, clean, and raw.
- Avoid markdown bold inside itinerary activity bullets.

4. Make itinerary more intelligent
Update the prompt so itinerary planning feels practical and logical:
- account for arrival/departure timing
- avoid overpacking
- avoid repetitive activities
- avoid filler activities
- prioritize quality over filling every slot
- keep mobile response concise
- preserve existing no hotel/car/commute rules

5. Review existing feedback
Review any feedback already provided by the coding/QA agent and incorporate valid improvements into the prompt.
