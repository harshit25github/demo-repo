Fix Flight-specific `suggestedQuestions` issue in Summary Extractor Agent only.

## Scope

Work only on the Summary Extractor Agent.

Do not modify:
- Flight Agent
- Trip Planner Agent
- Policy Agent
- Page Specific Agent
- Gateway routing
- UI/client code
- Any unrelated shared logic

Other agents should keep existing behavior unchanged.

## Current workflow

1. User request comes to Gateway Agent.
2. Gateway handles guardrails and routes/handoffs to one of these agents:
   - Flight Agent
   - Trip Planner Agent
   - Policy Agent
   - Page Specific Agent
3. Agent responds through streaming.
4. During/after streaming, we can identify the last triggered agent.
5. After the main response is complete, Summary Extractor Agent runs.
6. Extractor Agent receives:
   - old summary context
   - current user message
   - current agent response
7. Extractor Agent updates the summary object and generates:
   - `suggestedQuestions: string[]`

These questions are shown in UI as “You might ask”.

## Problem

For Flight Agent, there is a strict rule:

Flight Agent must never recommend or choose these 3 mandatory fields:
- origin
- destination
- travel dates/date range

These values must always come from the user.

But Summary Extractor Agent sees missing context and generates bad suggestions like:
- "Add a destination for me"
- "Pick an origin for me"
- "Suggest travel dates"
- "What are the best travel dates?"
- "Choose a destination"
- "Where should I fly from?"

This is wrong because it creates contradiction with Flight Agent behavior.

## Required solution

Pass one new field to Summary Extractor Agent:

```ts
lastAgent: string
````

Example extractor input:

```ts
{
  oldSummaryContext,
  currentUserMessage,
  currentAgentResponse,
  lastAgent
}
```

`lastAgent` should come from the actual agent triggered during streaming.

## Dynamic instruction handling

Update Summary Extractor Agent instructions dynamically based on `lastAgent`.

If `lastAgent` is Flight Agent, add a strict instruction:

Never generate `suggestedQuestions` where the user asks the agent to choose/recommend/provide:

* origin
* destination
* travel dates/date range

Blocked Flight suggestions:

* "Pick a destination for me"
* "Suggest where I should fly"
* "Choose my travel dates"
* "Find me a destination"
* "Suggest a departure city"
* "What are the best travel dates?"
* "Add origin for me"
* "Add destination for me"

Allowed style:
Suggestions should still be genuine user-side actions, but not related to asking the agent to choose origin/destination/date.

Examples of safer suggestions:

* "Change cabin to economy"
* "Change trip type to round trip"
* "Add 2 adults"
* "Update passenger count"
* "Use premium economy"
* "Make it a one-way search"

Important:

* Do not force suggestions if they do not fit.
* Keep them natural and relevant to the latest user message and agent response.
* Do not reuse stale suggestions from old summary context.
* Do not ask questions that look like the agent is asking the user.
* Suggestions must look like something the user would ask the agent.

## Expected behavior

If `lastAgent` is Flight Agent:

* No origin recommendation suggestions
* No destination recommendation suggestions
* No travel date recommendation suggestions
* Suggestions should remain relevant and genuine

If `lastAgent` is not Flight Agent:

* Existing extractor behavior should remain unchanged.

## Add protection

Prompt-only may not be enough, so add a small deterministic sanitizer inside Summary Extractor Agent output flow.

For Flight Agent only:

* Remove any suggested question related to choosing/recommending origin.
* Remove any suggested question related to choosing/recommending destination.
* Remove any suggested question related to choosing/recommending travel dates.
* Remove duplicates/stale suggestions.

## Tests

Add tests for:

1. `lastAgent = Flight Agent`

   * Output must not contain origin/destination/travel-date suggestions.

2. `lastAgent = Flight Agent`, missing destination in summary

   * Still must not suggest “pick/suggest/add destination”.

3. `lastAgent = Flight Agent`, missing origin in summary

   * Still must not suggest “pick/suggest/add origin”.

4. `lastAgent = Flight Agent`, missing date in summary

   * Still must not suggest “pick/suggest/add travel date”.

5. `lastAgent = Trip Planner / Policy / Page Specific`

   * Existing behavior should not break.
